# Legacy Preview — giữ để regression only

Những mã trong thư mục này thuộc bản Preview trước khi thiết kế Trusted Control Plane. Không cài bằng `install.py` cũ vào repository sản phẩm và không dùng `AGENTS.md`/hooks cũ như cơ chế Strict Approval. Bản tích hợp mới có CLI `tools/agentflow.py` và hướng dẫn chính thức dưới `guides/`; hiện chỉ **guidance-only và read-only/draft**.
